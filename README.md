# Online_Machine_Learning_via_Flink

Distributed High Scale Online Machine Learning via Apache Flink

The Middleware of the Online Machine Learning and Data Mining component.

This is a framework for parallel stream-processing computation algorithms,
similar in spirit to Google's Pregel or Apache Hama (although both are modeled after
Valiant's BSP architecture, but this system isn't)
